## 추천: Resend

Next.js/Vercel 스택(이 프로젝트들과 동일 조합)에 가장 궁합이 좋음.

- **무료 티어**: 월 3,000통까지 무료(영구, 기간제 트라이얼 아님)
- **유료 시작가**: Pro $20/월(월 5만통), React Email로 템플릿을 JSX로 작성 가능(이 프로젝트들이 이미 React 기반이라 그대로 재사용 가능)
- **설정 난이도**: API 키 발급 + 도메인 DNS 인증(SPF/DKIM) 정도로 약 15분 내 세팅 가능
- **적합한 경우**: 회원가입 인증메일, 알림메일, 뉴스레터 등 대부분의 이 프로젝트군 용도

## 결론

- **지금 이 프로젝트 규모(개인/소규모 SaaS)라면 Resend로 시작**할 것 — 무료 티어로 충분히 오래 버티고, 나중에 물량 늘면 그때 SES로 이전 검토
- 발송량이 월 수십만 통 이상으로 커지면 그때 AWS SES 이전을 검토(비용 역전 지점)
